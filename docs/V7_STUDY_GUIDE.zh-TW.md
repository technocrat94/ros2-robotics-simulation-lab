# v7 讀書筆記：相機看到棒子 → 手臂閃開

寫給自己看的版本。不講程式細節，只講「每一塊在做什麼、重要數字在哪、出問題先看哪」。
主程式：`scripts/curobo_v7_mapper.py`（下面寫 `:25` 就是第 25 行）。

---

## 1. 今天應該學會的 5 件事

1. **整條流程只有四步**：相機拍深度 → 去掉手臂自己 → 拼成 3D 地圖 → MPC 根據地圖算下一步。
   這是 NVIDIA cuRobo 官方範例 `live_volumetric_mapping_mpc.py` 的做法，我們照抄，不自己發明。
2. **兩台相機互補**：固定相機看全景（不會被手臂帶著亂晃）；手上相機看近處細節。兩張圖拼進同一張地圖。
3. **「挖掉手臂」的範圍要量，不要猜**：挖太少，手臂會把自己當成障礙物；挖太多，靠近手臂的棒子也被挖掉。
   我們量出來的是 15 mm（底座另外照它的實際形狀挖）。
4. **MPC 是「短視」的**：它每 0.025 秒重算一次，但只往前看約 0.4 秒。
   好處是反應快；壞處是棒子正好擋在直線上時，它想不到「繞遠路」，只會停在前面等（這叫局部最小值）。
   解法是下一步的 **planner + MPC**：planner 先規劃整條路線，MPC 沿著路線即時閃避。
5. **驗收要按順序，而且要公平**：A0 → A → B → E，第一關沒過就停，先修那一關。
   - A0：沒有棒子。確認路本身走得通，排除「手臂本來就到不了」。
   - A：有棒子，但故意不讓手臂知道 → **一定要撞到**。沒撞到代表棒子根本沒擋路，測試沒意義。
   - B：直接告訴手臂棒子的正確位置 → 一定要成功。沒過就是**規劃**的問題，跟相機無關。
   - E：只靠相機 → 一定要成功。B 過但 E 沒過，就是**相機/地圖**的問題。

```
        │

        │
        ▼
 ② RobotSegmenter 把「手臂自己」的像素挖掉（15 mm）                :43, :237
    + 底座盒子挖掉 + 地板(z ≤ 1.2 cm)挖掉                          :170, :287
        │
        ▼
 ③ Mapper        把像素拼成 3D 方格地圖（5 mm 一格）                :240
    compute_esdf 算出「每一點離最近障礙物多遠」（3 cm 一格）
        │
        ▼
 ④ MPC           找一串動作：靠近目標、離障礙物 ≥ 7 cm 開始推開      :308, :34

        │
        ▼
 Newton 模擬手臂照著動 → 回到最上面再拍下一張
```

## 4. 規劃限制（MPC 會遵守什麼）

| 限制 | 數值 | 意思 | 在哪 |
|---|---|---|---|
| 障礙物推開距離 | 7 cm | 離障礙物 7 cm 內就開始被「推開」。算法：手臂靠近速度 0.5 m/s × 反應時間 + 棒子 0.1 m/s × 0.43 s | `:34` |
| 地板推開距離 | 1 cm | 地板不會動，所以留小一點，不然手臂不敢低 | `:35` |
| 控制週期 | 0.025 s | 每 0.025 秒送一次指令 | `:27` |
| 規劃步長 | 0.02 s | MPC 內部一步的時間 | `curobo_moving_rod_mpc_tuned.py:26` |
| 加速度懲罰 | 10000 | 越大動作越平順，但反應越慢 | 同上 |
| 中途姿勢權重 | 0.3 | 中途也要盡量對準目標方向，不要亂扭 | 同上 |
| 手腕第 3 軸 | 只能在起始角度 ±180° 內轉 | 防止相機線纏住 | `curobo_camera_fifth_pass.py:134` |
| 關節速度/加速度 | UR5 官方上限 | 在機器人設定檔裡 | `--robot-config` |
| 回程 | 同時追「位置」跟「驗證過的關節角度」 | 防止它換成另一種手肘姿勢就回不來 | `:688` |

## 5. 出問題先看哪裡（排錯地圖）

| 你看到的現象 | 最可能的原因 | 先查 |
|---|---|---|
| 手臂一直抖、閃爍、亂動 | 手臂把自己當障礙物（挖得不夠） | ② 挖手臂距離 `:43` |
| 靠近棒子時撞上去 | 棒子被挖掉了（挖太多），或棒子太快、推開距離太小 | ② `:43` / ④ `:34` |
| 地圖上有東西一直不消失 | 衰減設定；或那塊相機看不到，沒機會更新 | `:41` 衰減 |
| 地圖有洞、棒子只出現一半 | 被手臂擋住、在相機範圍外、或太近 (< 0.15 m) | ① `:25`、相機位置 |
| 停在棒子前面不動 | MPC 局部最小值（不會繞遠路） | 要靠 planner + MPC |
| 到了終點不回來 / 回程卡住 | 換到另一種手肘姿勢 | 回程設定 `:688` |
| 手臂碰到地板 | 地板推開距離 | ④ `:35` |
| B 過、E 沒過 | 問題一定在相機 / 地圖（①②③） | 第 2 節流程圖 |
| B 也沒過 | 問題在規劃（④）或場景本身不公平 | 先跑 A0、A |
| 互動畫面打不開 / 沒在動 | port 不對（應該是 30006），或程式已經停了 | `scripts/run_sim_camera_v7.sh` |

**口訣**：先分是「看」的問題還是「想」的問題。B 過了就是「看」的問題，B 沒過就是「想」的問題。
